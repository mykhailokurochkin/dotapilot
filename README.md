# DotaPilot 🛡️⚡

> **DotaPilot** — надлегкий, 100% легальний (VAC-безпечний) AI-коуч та прозорий HUD-асистент для Dota 2 у реальному часі на базі офіційного Valve Game State Integration (GSI).

---

## ✨ Ключові можливості

* **100% VAC-безпека та легальність:** DotaPilot використовує виключно офіційний протокол Valve GSI (Game State Integration через локальний HTTP). Жодних DLL-ін'єкцій, читання пам'яті чи автоматизації кліків.
* **Zero-Lag архітектура (оптимізовано під Mac Apple Silicon):**
  * `throttle 3.0`: гра надсилає пакети не частіше одного разу на 3 секунди (зниження навантаження на рушій Source 2 на 90%).
  * **Автономний локальний таймер:** інтерфейс веде плавний посекундний відлік автономно, синхронізуючись із GSI та миттєво реагуючи на ігрові паузи (`⏸️ ПАУЗА`).
  * **Мікро-док оверлей (370×450 px):** замість важкого повноекранного прозорого шару використовується компактний кутовий WebKit-док. Навантаження на композитор macOS WindowServer знижено на 96.5% (**0.0% CPU** під час гри).
* **Стелс-режим (Чистий екран):** 95% часу оверлей не заважає огляду і не перекриває рідний таймер, портрети героїв чи мінікарту.
* **Ефемерні спливаючі сповіщення (Toasts):**
  * 🎁 Відкриття тирів нейтральних предметів (07:00, 17:00, 27:00, 37:00, 60:00).
  * 👹 Попередження про Терзателя на 19:45.
* **Інтерактивна Таверна (Tavern Mode):**
  * Автоматично з'являється у разі загибелі героя із живим зворотним відліком респавну.
  * Генерує глибоку макро-пораду від **Gemini AI (Immortal-рівень)**: який наступний слот купувати під поточну ситуацію і роль, та яку ділянку карти контролювати після відродження.
  * Повністю безшовна: миттєво і тихо зникає, щойно герой відроджується.
* **Два режими роботи:**
  1. **Нативний macOS оверлей (`DotaPilotOverlay`):** напівпрозоре плаваюче вікно з наскрізними кліками.
  2. **Веб-дашборд (`http://localhost:3000`):** для відкриття у браузері або на другому моніторі / планшеті.

## 🚀 Швидкий старт

### 1. Встановлення залежностей
```bash
git clone https://github.com/mykhailokurochkin/dotapilot.git
cd dotapilot
pnpm install
```

### 2. Налаштування API-ключа Gemini
Створіть файл `.env` у корені проєкту:
```bash
GEMINI_API_KEY=your_gemini_api_key_here
```
*(Отримати безкоштовний ключ можна на [Google AI Studio](https://aistudio.google.com/)).*

### 3. Автоматичне підключення до Dota 2
Встановіть GSI-конфігурацію в папку гри:
```bash
pnpm run install:cfg
```
Це автоматично створить та розмістить `gamestate_integration_dotapilot.cfg` у вашій директорії:
`.../dota 2 beta/game/dota/cfg/gamestate_integration/`

### 4. Запуск

#### Варіант А: Сервер + Нативний оверлей
```bash
# Запуск GSI-сервера з live auto-reload
pnpm dev

# В окремому терміналі — запуск прозорого HUD-вікна:
pnpm run overlay
```

#### Варіант Б: Тільки веб-дашборд
```bash
pnpm start
# Відкрийте у браузері: http://localhost:3000
```

## 🛠️ Скрипти розробки

| Команда | Опис |
| :--- | :--- |
| `pnpm dev` | Запуск сервера у режимі розробки з авто-перезавантаженням (`--watch`) |
| `pnpm start` | Звичайний запуск сервера DotaPilot |
| `pnpm run overlay` | Запуск нативного macOS Cocoa + WebKit оверлею |
| `pnpm run build:overlay` | Компіляція нативного бінарника оверлею через `clang` |
| `pnpm run stop` | Зупинка всіх процесів DotaPilot |
| `pnpm run mock` | Симуляція катки тестовими GSI-пакетами |

## 🏗️ Архітектура

```
dotapilot/
├── src/
│   ├── index.ts                # Точка входу застосунку
│   ├── gsi/
│   │   └── server.ts           # HTTP-сервер для прийому GSI та стрімінгу SSE
│   ├── ai/
│   │   └── advisor.ts          # Інтеграція з Gemini API (flash-lite / flash)
│   ├── rules/
│   │   └── timers.ts           # Математика таймерів і перевірки байбеку
│   ├── overlay/
│   │   └── main.m              # Нативний Objective-C Cocoa + WebKit мікро-док
│   ├── web/
│   │   ├── dashboard.html      # Повний веб-інтерфейс аналітики
│   │   └── overlay.html        # Прозорий HUD стелс-оверлей
│   └── scripts/
│       ├── install-cfg.ts      # Авто-встановлювач GSI-конфігу в Доту
│       ├── send-mock.ts        # Базовий мок-генератор
│       └── simulate-match.ts   # 60-секундний сценарій симуляції
├── gamestate_integration_dotapilot.cfg # Еталонний конфіг для Dota 2
└── package.json
```
